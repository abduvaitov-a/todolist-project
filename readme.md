# 📝 Modern Django To-Do App

Современное веб-приложение для управления задачами (To-Do List), разработанное на **Django** с использованием **Bootstrap 5** и **Bootstrap Icons**. Проект поддерживает полноценную аутентификацию пользователей и удобный адаптивный интерфейс.

---

## ✨ Основные возможности

* **🔐 Аутентификация:** Регистрация, вход в систему и безопасный выход.
* **📋 Управление задачами:** Создание, редактирование, удаление задач и изменение их статуса («Готово» / «Вернуть»).
* **🔒 Безопасность:** Каждый пользователь видит и управляет только своими собственными задачами.
* **🎨 Современный дизайн:** Интерфейс на Bootstrap 5 с мягкими тенями, карточками и иконками.
* **📱 Поддержка переноса строк:** Описания задач сохраняют форматирование и списки.

---

## 🛠 Технологии

* **Python 3.x**
* **Django 6.1**
* **Bootstrap 5 & Bootstrap Icons**
* **SQLite** (база данных по умолчанию)
